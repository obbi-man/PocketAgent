Политика конфиденциальности приложения PocketAgent

Дата вступления в силу: 19 ноября 2026 г.
Разработчик: автор приложения PocketAgent (учётная запись GitHub obbi-man).
Приложение: PocketAgent, пакет ru.pocketagent.

1. Коротко

PocketAgent — бесплатный голосовой и текстовый помощник. Языковая модель работает на самом телефоне. У разработчика нет своих серверов, приложение не создаёт учётных записей, не собирает и не продаёт данные пользователей, не показывает рекламу и не использует аналитику или трекеры.

2. Какие данные хранятся на устройстве

Только во внутренней памяти приложения (и не попадают в облачную резервную копию Android, так как резервное копирование приложением отключено):

  • заметки, напоминания, будильники и таймеры, созданные пользователем;
  • история диалога с помощником;
  • факты, которые пользователь явно попросил запомнить, и настройки стиля общения (если память включена) — их можно посмотреть, изменить, удалить или полностью отключить в разделе «Что я о вас знаю»;
  • настройки приложения, в том числе выбранная модель и мелодия напоминаний;
  • локальные записи о сбоях — их можно скопировать только вручную, разработчику они сами не отправляются.

Эти данные не передаются разработчику. Они удаляются при удалении приложения или очистке его данных в настройках Android.

3. Микрофон и речь

Разрешение на запись звука нужно только для голосового ввода, когда пользователь сам нажимает кнопку микрофона или включает «живой режим». Распознавание речи выполняет системный сервис на телефоне (например, Samsung или Google). Если доступно распознавание на устройстве, звук не покидает телефон; иначе обработка регулируется политикой поставщика этого сервиса. PocketAgent не сохраняет и не отправляет аудиозаписи. Ответы вслух произносит системный синтезатор речи телефона.

4. Текст с экрана и файлы

Если пользователь назначает PocketAgent цифровым помощником по умолчанию и включает в системе анализ текста на экране, система может передать приложению видимый текст (и при желании снимок) текущего экрана — только для текущего обращения «спросить про экран». Этот текст читается на телефоне и не сохраняется: он забывается при закрытии окна помощника.

Прикреплённые или присланные файлы (например, PDF или текст) читаются на устройстве, чтобы ответить на вопрос по их содержимому. Разработчик эти файлы не получает.

Если включено дублирование заметок, текст заметки передаётся выбранному пользователем приложению заметок (например, Samsung Notes или Google Keep) и дальше хранится по правилам этого приложения.

Будильники и таймеры по запросу пользователя могут создаваться в системном приложении «Часы».

5. Обращения в интернет (необязательные)

Если включён «Поиск в интернете» (по умолчанию включён) и есть сеть, текст запроса (например, «погода в Екатеринбурге» или «кто такой …») отправляется напрямую в публичные сервисы:

  • Википедия (ru.wikipedia.org) — справочные ответы, тексты по лицензии CC BY-SA;
  • DuckDuckGo (html.duckduckgo.com) — веб-поиск;
  • Open-Meteo и wttr.in — погода (передаётся название города; данные Open-Meteo — CC BY 4.0);
  • курсы Банка России через cbr.ru / cbr-xml-daily.ru;
  • Google Новости (news.google.com) — заголовки новостей.

Вместе с запросом эти сервисы видят IP-адрес устройства, как при обычном открытии сайта. Каждый сервис обрабатывает данные по своей политике. Поиск можно выключить в настройках, тогда ответы модели не используют сеть.

В облегчённой версии при первом запуске (и при смене модели) с Hugging Face (huggingface.co) или его зеркала (hf-mirror.com) по команде пользователя скачивается файл языковой модели. Личные данные при этом не передаются.

Ссылки из ответов открываются в браузере только после подтверждения пользователя.

6. Остальные разрешения

  • Уведомления, точные будильники, показ на заблокированном экране, вибрация, запуск после перезагрузки и работа в фоне со звуком — чтобы напоминания срабатывали вовремя, в том числе с мелодией.
  • Роль помощника по умолчанию — чтобы вызывать PocketAgent жестом или кнопкой вместо другого ассистента.
  • Доступ к сети и состоянию сети — только для функций из раздела 5 (и, в сборках не из RuStore, для проверки обновлений с Google Диска разработчика по согласию пользователя). В сборке для RuStore автообновление выключено: обновления приходят из магазина.

7. Дети

Приложение не предназначено специально для детей и сознательно не собирает данные детей. Ответы языковой модели не модерируются как детский контент и могут быть неточными.

8. Изменения

При изменении политики новая версия публикуется по этому адресу с новой датой вступления в силу.
